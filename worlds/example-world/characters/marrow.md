# Marrow

- **Appearance:** weathered, oilskin coat, one lamp-blind eye.
- **Manner / Voice:** terse, answers questions with questions.
- **Wants:** the fourth light put out before the town notices it.
- **Secrets:** (host-only) Marrow lit the fourth light himself. See [The Fog](../lore/the_fog.md).
